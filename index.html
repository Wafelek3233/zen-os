What is Zen OS?

A desktop operating system built on Debian 13 "Trixie". We keep Debian's rock-solid base and add our own installer, theme and updater on top — so it feels like one finished product.

⇄Two update channels

Feature Updates refresh everyday packages through apt. System Updates deliver a whole new system image over the air (OTA), verified by checksum before anything touches your disk.

◫Your desktop, your choice

Pick KDE Plasma, GNOME, XFCE, Cinnamon, MATE or LXQt during install. Zen OS adapts — the updater and installer work the same on all of them.

◍Zen Update

One window for everything: package upgrades, full system releases with a release card (banner, name, version), and a confirmed, non-destructive install plan.

⤓Made to be installed

A graphical installer with language selection, a 3-second-confirmation safety step for storage, and a Windows USB writer so you can flash the ISO without touching a terminal.

New to Linux? These are the three ideas behind everything Zen OS does.

▤What is a distro?

A "distribution" is Linux plus everything around it: packages, installer, desktop. Zen OS is a distro built on Debian — like a finished house built on a very solid foundation.

⇪What is OTA?

"Over-the-air" means the whole system image travels from our server to your machine, like a phone update. We sign and checksum it, so what you install is exactly what we published.

⌸What is apt?

Debian's package manager. It installs and upgrades individual programs. Zen Update wraps it in a friendly window so you never have to memorise commands.
